Question 3: Hardy–Weinberg Equilibrium (HWE) Test

  1. Conduct the Hardy–Weinberg Equilibrium (HWE) test for all SNPs in the .bim file. Then, load the file containing the HWE p-value results and display the first few rows of the resulting data frame.
hwe_pvalue <- function(geno_vector) {
  # Remove missing
  geno_vector <- geno_vector[!is.na(geno_vector)]
  # Count genotypes
  counts <- table(geno_vector)
  
  # Check if there are enough counts to test
  if (any(counts == 0)) {
    return(NA)  # Cannot test properly with empty cell
  } else {
    result=HWExact(as.numeric(counts))$pval
    #result=HWChisq(as.vector(counts))$pval
    return(result)
  }
}
